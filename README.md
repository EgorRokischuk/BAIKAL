# IS-BAIKAL
The client part of a web application for analyzing the Baikal natural area using satellite data.

## Stack
- Typescript
- [React](https://react.dev/)
- [Webpack](https://webpack.js.org/)
- [Redux](https://redux.js.org/)
- [Prettier](https://prettier.io/)
- [Commitlint](https://commitlint.js.org/)

## Development Methodology - *Feature Sliced Design*
- [Description of the methodology](https://feature-sliced.design/ru/docs/get-started/overview)
- [Presentation](https://fsd-seven.vercel.app/)

# Scripts Description
## Build Application Version
- npm run build

## Start Development Server:
#### With Mock Data
- npm run devlocal
#### Using API
- npm run devserver
